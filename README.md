# Eats

В данном проекте я реализовал веб-приложение практически с нуля, используя **React**. В данном приложении также была проведена работа с API с использование библиотеки **React-Query**.

### Описание работы приложения

В данном приложении перед вами откроется 4 карточки разных ресторанов, Вы сможете поставить оценку каждому ресторану, нажав на ту звезду по счету (слева направо), на которую Вы даете оценку (например, если Вы нажимаете на 4ую звезду, Вы, таким образом, даёт ресторану оценку 4/5). Также в приложении есть поисковая строка, с помощью которой Вы сможете найти ресторан из списка.

### Запуск приложения
Для того, чтобы запустить проект надо:

1. Открыть проект и запустить терминал

2. Установить необходимые зависимости, для этого в терминале надо прописать:

   ```bash
   npm install
   ```

3. Запустить приложение, для этого в терминале надо прописать:

   ```bash
   npm run dev
   ```

4. После запустка в терминале появится строка с ссылкой по которой надо перейти:

[1]   ➜  Local:   http://localhost:5173/
